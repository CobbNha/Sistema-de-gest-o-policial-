# SIAC

Sistema Inteligente de Análise Criminal.

## Estado

Esta versão inicial contém um protótipo visual com dados fictícios.

## Tecnologias

- Next.js App Router
- React
- TypeScript strict
- Zod
- Neon PostgreSQL / Drizzle ORM — planeados
- Vercel

## Desenvolvimento

```bash
npm install
npm run dev
```

Dados policiais reais não devem ser introduzidos sem validação institucional, jurídica, de segurança e privacidade.
